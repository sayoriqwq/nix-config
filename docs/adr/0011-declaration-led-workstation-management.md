# 以声明驱动受管工作站的日常维护

状态：已接受，2026-09-13。维护者明确选择 Nix 声明与 lock 作为受管期望状态的唯一真源，日常安装、版本更新与长期设置调整服务于声明的应用和重建。这取代此前“现场可独立演进、按需捕获基线”作为受管资源默认维护方式的约定；现场仍是实际状态的证据，私有记录与数据备份保持独立。

此选择接受维护声明、审阅更新范围与验证实际行为的成本，以获得可靠重建能力。先通过 nh 和必要的薄包装降低操作成本，不因一次更新摩擦改变安装所有权，也不另造软件清单或声明系统。具体保证及日常规则由[主工作站管理](../architecture/workstation-management.md)定义。

“唯一真源”限于已表达的受管范围。原生安装与现有 Homebrew 集成仍可采用，但其安装需求、运行版本、设置保存与数据恢复保证须分别说明。现有 Zed 原生更新等具体决定不由本 ADR 自动撤销，软件迁移需另有范围与证据。本次仅确立维护方向，不声称已完成设置纳管、更新包装或换机恢复验证。
