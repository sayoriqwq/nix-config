# 可选的 Issue 与 PR 协作

使用时机、外部写入授权和完成条件见 [Agent 协议](../../AGENTS.md#3-routine-work)。本文只说明需要 Issue/PR 时如何组织记录。

Issue 用中文说明目标、涉及的对象或主机、必要依赖、验证方法和完成条件。只有涉及风险或真实机器动作时，再补充具体操作、停止条件、读回与回滚。字段按任务需要组织，不要求额外英文 Agent Contract。

PR 用中文说明问题与结果、范围、验证结果和相关风险；有对应 Issue 时关联它。尚未执行的实机验证、待批准动作和未决事项必须如实列出。

记录需要跨会话保留的计划、决定与完成证据，不复制整段聊天或私有现场。

需要标签时参考 [triage-labels.md](triage-labels.md)。
