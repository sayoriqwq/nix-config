# 可选 Issue 标签

标签只帮助检索和说明状态，不提供授权，也不决定能否工作。没有标签、标签未创建或状态尚未切换，都不阻止已明确范围内的工作；事实和授权以当前请求及相关正文、评论为准。

按需要复用以下已有词汇，保持最小集合：

| 类别 | 可选标签 | 用途 |
| --- | --- | --- |
| 状态 | `needs-triage`、`needs-info`、`blocked` | 待定范围、缺少必要事实或存在实际依赖 |
| 交接 | `ready-for-agent`、`ready-for-human` | 说明下一步由谁处理，不构成领取或批准门槛 |
| 结果 | `wontfix` | 记录不再实施的决定及原因 |
| 类型 | `type:maintenance` | 普通维护、重构或依赖更新 |
| 范围 | `area:governance`、`area:darwin`、`area:home`、`area:nixos`、`area:server`、`area:secrets` | 帮助按对象检索 |
| 风险 | `risk:activation`、`risk:remote-access`、`risk:destructive` | 提醒阅读正文中的具体影响与安全条件 |

不要求维护者先切换标签。标签与内容不一致时，按事实和已有授权判断；若差异影响下一步安全或范围，说明冲突并澄清该部分。只有获得 GitHub 修改授权时才更新标签，不默认创建新标签或整理颜色。
